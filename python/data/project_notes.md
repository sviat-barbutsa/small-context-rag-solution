# Project Notes

The project is a local document question answering assistant.

It uses LM Studio as a local OpenAI-compatible server.

The chat model is Gemma through the model id gemma-4-e4b-it.

The embedding model is Nomic Embed Text through the model id text-embedding-nomic-embed-text-v1.5.

The first milestone is basic RAG without an agent.

Later milestones include a LangChain agent, short-term memory, context pressure experiments, human confirmation with LangGraph, and finally Deep Agents.
