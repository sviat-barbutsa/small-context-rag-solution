# LangChain Notes

LangChain is a framework for building applications with language models.

It provides abstractions for chat models, prompts, messages, tools, agents, retrieval, and memory.

For this project, LangChain will be used first for document retrieval and a simple local assistant.

LangGraph will be added later for stateful orchestration, human approval, and pause/resume workflows.

Deep Agents will be evaluated later after the LangChain and LangGraph basics are understood.
